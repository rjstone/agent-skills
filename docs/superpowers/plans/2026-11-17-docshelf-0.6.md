# docshelf 0.6 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add `suggest` (docvols from a project's build files), sturdier
docset anchors in `show`, and a one-time "documentation lookups"
preference flow for agents.

**Architecture:** `suggest` is a new module `shelf_suggest.py` (file
parsers -> findings -> matches against installed docvols and the cached
DevDocs list), registered in the existing `COMMANDS` table so the CLI and
MCP get it together. Anchors are fixed inside the existing HTML-to-blocks
parser (`shelf_render.py`). The preference flow is Markdown only: a new
`references/lookup-defaults.md` plus one line in `SKILL.md`.

**Tech Stack:** Python 3 stdlib only (`tomllib` when Python >= 3.11),
`unittest`.

**Spec:** `docs/superpowers/specs/2026-11-17-docshelf-0.6-design.md`

## Global Constraints

- Stdlib only; no install step. `tomllib` only behind
  `sys.version_info >= (3, 11)`; on older Python, TOML files are skipped
  with a note.
- Version 0.6.0 in both `skills/docshelf/SKILL.md` `metadata.version` and
  `shelf_core.VERSION`; tests never contain the literal.
- `suggest` never uses the network and never writes `.docshelf.json`.
- Tier 1 files only (list in the spec); Tier 2 and Java build files are not
  read and not added to TODO.md.
- Public-repo rules (AGENTS.md): no user names, hostnames or absolute
  paths in committed files; fixtures under temp folders.
- Tests go in `tests/test_docshelf.py` (the CI selector maps that file to
  the skill), hermetic: use `clean_env()` / `run_cli()` and the existing
  `make_devdocs`, `make_docset`, `row` helpers.
- Run all tests from the repo root:
  `python3 -m unittest discover -s tests` (422 pass before this work).

## Review Focus

1. A malformed build file (bad JSON in `package.json`, a TOML syntax error,
   binary junk in `Dockerfile`): `suggest` notes the file on stderr and
   skips it, never a traceback. Test in Task 2.
2. Heavy folders next to the root (`node_modules/`, `.venv/`, `.git/`,
   `build/`): never scanned, even when they contain `package.json`. Test
   in Task 2.
3. Non-numeric versions (`.nvmrc` = `lts/iron`, `.python-version` =
   `system`, `FROM node:latest`): no pin, the family's newest, no crash.
   Tests in Tasks 2 and 3.
4. Nothing cached and nothing installed: a note that `sources` (network)
   would find more, an empty `"docvols": []`, exit 0. Test in Task 3.
5. Anchors with `%20`/spaces, and a page whose anchor appears both as a
   dashAnchor and as an `id` on a later block: the first block in page
   order wins. Test in Task 1.

def test_dash_anchor_before_heading(self):
    html = ('<a name="//apple_ref/cpp/Function/foo" class="dashAnchor"></a>'
            '<h3>foo()</h3><p>does foo</p><h3>bar()</h3><p>bar</p>')

    html = ('<dl><a name="//apple_ref/cpp/Function/os.path.join" class="dashAnchor"></a>'

### Task 2: Build-file parsers (`shelf_suggest.py`, scanning)

**Files:**
- Create: `skills/docshelf/scripts/shelf_suggest.py`
- Test: `tests/test_docshelf.py` (new class `SuggestScanTests`)

**Interfaces:**
- Produces:
  - `class Finding(NamedTuple): kind: str  # "lang" or "lib"`;
    `names: Tuple[str, ...]  # candidates, most specific first, normalized`;
    `version: str  # "" when none or not a plain number`;
    `source: str  # path relative to the scan root, "/" separators`
  - `normalize(name: str) -> str`: lowercase, runs of `-_.` -> `-`.
  - `scan_project(root: str) -> Tuple[List[Finding], List[str]]`:
    findings in file order, plus notes (skipped files, old Python).
  - `PARSERS: Dict[str, Callable[[str], List[Finding]]]` keyed by file name;
    `requirements*.txt` matched by pattern.
- Parser rules (the source of truth for the tests):
  - `package.json`: libs from `dependencies` + `devDependencies`; lang
    `javascript`; lang `node` with version from `engines.node` (first
    `\d+(\.\d+)*`) only when `engines.node` exists. npm names: `@types/x` ->
    `("x",)`; `@scope/x` -> `("scope", "x")`; else `(name,)`.
  - `pyproject.toml`: lang `python` (version from `requires-python` /
    Poetry `python` only when it is `==X.Y[...]` or a bare `X.Y`); libs from
    `project.dependencies`, every list in `project.optional-dependencies`,
    and `tool.poetry.dependencies` keys except `python`.
  - `requirements*.txt`: lang `python`; each line's name =
    `re.match(r"[A-Za-z0-9][A-Za-z0-9._-]*")` after stripping comments;
    skip blank lines and lines starting with `-`.
  - `CMakeLists.txt`: lang `cmake`; lang `cpp` when `CMAKE_CXX_STANDARD`
    is set; libs from `find_package(Name` (case-insensitive command).
  - `Cargo.toml`: lang `rust`; libs = keys of `dependencies`,
    `dev-dependencies`.
  - `go.mod`: lang `go`, version from the `go 1.NN` line.
  - `Gemfile`: lang `ruby` (version from `ruby "X.Y"`); libs from
    `gem "name"` / `gem 'name'`.
  - `composer.json`: lang `php`; libs from `require` + `require-dev` keys
    `vendor/name` -> `("name", "vendor")`; skip `php` and `ext-*`.
  - `Dockerfile`: lang `docker`; each `FROM image[:tag]` (skip `scratch`
    and `AS` stage references) -> lib `(image,)` with the tag as version.
    Image: drop `@sha256...`, a registry first component (contains `.` or
    `:` or is `localhost`), and `library/`.
  - `docker-compose.yml`, `docker-compose.yaml`, `compose.yml`,
    `compose.yaml`: lang `docker`; each `image:` line like a `FROM`.
  - `.nvmrc`, `.node-version` -> lang `node`; `.python-version` -> `python`;
    `.ruby-version` -> `ruby` (strip a `ruby-` prefix); `.tool-versions` ->
    each `nodejs`/`python`/`ruby`/`golang`/`rust` line -> that lang
    (`nodejs` -> node, `golang` -> go). Version = the first
    `\d+(\.\d+)*` after an optional `v`; anything else (`lts/iron`,
    `system`, `latest`) -> `""`.
- Scan: the root, then each direct child folder holding at least one
  parser file, skipping hidden folders and `node_modules`, `venv`,
  `.venv`, `env`, `build`, `dist`, `target`, `vendor`. A parser error
  (`OSError`, `ValueError` incl. JSON/TOML errors, `UnicodeDecodeError`)
  becomes the note `note: skipped <source>: <reason>`.

### Task 3: Matching and the `suggest` command (CLI + MCP)

**Files:**
- Modify: `skills/docshelf/scripts/shelf_suggest.py` (matching, `cmd_suggest`)
- Modify: `skills/docshelf/scripts/shelf_devdocs.py` (new `cached_manifest`)
- Modify: `skills/docshelf/scripts/shelf_cli.py` (`COMMANDS` entry,
  `TOP_HELP` line)
- Test: `tests/test_docshelf.py` (new class `SuggestTests`; one MCP
  assertion in it)

**Interfaces:**
- Consumes: `scan_project`, `Finding` (Task 2);
  `shelf_backends.installed_docvols(cfg)`, `shelf_backends._major_minor`.
- Produces:
  - `shelf_devdocs.cached_manifest(cfg: Config) -> Optional[List[dict]]`:
    the cached `docs.json` rows at any age, `None` when missing or
    unreadable; never fetches.
  - `ALIASES: Dict[str, str]` normalized dependency name -> DevDocs family.
    Seed: `react-dom`/`react-native-web` -> `react`, `vue-router` -> `vue`,
    `typescript` -> `typescript`, `postgres` -> `postgresql`, `golang` ->
    `go`, `httpd` -> `apache_http_server`, `qt6`/`qt5` -> `qt`, `numpy`,
    `pandas`, `django`, `flask` identity; extend it from DevDocs families
    as you see fit, verifying each family exists in a current `docs.json`
    (use the fixture style, not the network, in tests).
  - `class Suggestion(NamedTuple): name: str  # docvol or slug to list`;
    `status: str  # "installed", "docset" or "available"`;
    `sources: List[str]`; `note: str  # "" or e.g. "no 3.9 docs; newest is 3.14"`
  - `match(findings: List[Finding], installed: List[Docvol],
    manifest: Optional[List[dict]]) -> Tuple[List[Suggestion], int]`:
    suggestions (first-found order, one per name, sources merged) and the
    count of distinct unmatched lib findings.
  - `cmd_suggest(cfg: Config, args) -> int` (always 0 unless a usage error).
- Matching rules: for each candidate name in order, the family is
  `ALIASES.get(n, n)`; it matches an installed docvol whose `family` or
  `aliases` contain it, else a manifest row whose `slug.split("~")[0]` or
  `alias` equals it. With a finding version, prefer the docvol/row whose
  version (`row["version"]` or the slug suffix, `_` -> space) agrees on
  as many of the first two numbers as both have (`_major_minor`); rows
  are newest first, so take the first agreeing. No agreeing row: the
  newest, with a note. Installed beats available; a read-only docvol is
  status `docset`; its name is the docvol's `name`.
- Output (stdout), one line per suggestion:
  `<status padded to 9> <name>  (<sources joined ", ">)[  <note>]`,
  then a line `"docvols": [<json list of names>]`, then
  `<n> dependencies matched no docvol` when n > 0. Notes from the scan and
  `note: no DevDocs list cached; run sources (network) to find more` go to
  stderr. `--json`: `{"suggestions": [{name, status, sources, note}],
  "docvols": [...], "unmatched": n, "notes": [...]}` on stdout.
- Root: the folder of `cfg.project` if set, else the current folder.
- `COMMANDS` entry: `Command("suggest", "Suggest docvols from the
  project's build files (package.json, pyproject.toml, CMakeLists.txt,
  ...).", shelf_suggest.cmd_suggest, [Param(("--json",), "Print JSON.",
  kind="flag")])`, placed after `sources`. `TOP_HELP`, under "Get and
  manage docvols", before `sources`:
  `  suggest                        docvols for the project's build files`
  / `                                 and version files, then a "docvols"`
  / `                                 list to paste (no network)`.
