## Decisions

- 6.1.2: a link whose `..` climbs above the docvol root gets no REF (it is
  outside the docvol), instead of being clamped to a page at the root.
- 6.1.3: a docset's id -> entry lookup is a dict built once per docvol
  object, on first use.
- 6.2.4: a same-mtime reinstall counts as "up to date" only when
  `index.json`, `db.json` and `meta.json` all exist; otherwise reinstall.
  The page index is built once per install.
- 6.2.5: files docshelf writes through `mkstemp` get normal umask
  permissions (as `open()` would give). Before writing into a cache
  folder, remove `*.tmp` files there older than one hour (a killed run's
  leftovers); never touch other files.
- 6.2.6: `install` stores `entry_count` in `meta.json`; reading uses it
  and falls back to counting `index.json` for older installs (no write on
  the read path).
- 6.4.3: replace bare `except Exception` with the specific errors the code
  can raise (`OSError`, `ValueError`, `plistlib.InvalidFileException`,
  `sqlite3.Error`, `UnicodeDecodeError`, as applies).
- 6.4.5: tarix: the index prefix is probed once per docvol object; a read
  error (the exit-7 kind) while resolving a link prints one warning per
  docvol on stderr and the link gets no REF (not silent).
- 6.5.1: `where` prints every configured docset folder with its
  `[source]`, marking ones that don't exist `(missing)`.
- 6.5.2: within one process, each docset is opened once: share the
  discovery result between `where`/`list` and `installed_docvols`.
- 6.5.3: `list` prints "also as" once per docvol line, listing all its
  twins.
- 6.6.1: `repeats.json` items are type-checked on read; anything malformed
  means the cache is rebuilt.
- 6.6.2: the fts and headings index stamps include `REPEAT_FORMAT`, so a
  `REPEAT_FORMAT` bump rebuilds them automatically.
- 6.7.1: the "came from Zeal's catalog" note prints once per command.
- 6.10.1: the fts match expression is built once per query; the `ids`
  query strips punctuation from plain tokens (as the text query does).
