# docshelf 0.7.2 (tests and tidying) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Close the test-only, cleanup and small-fix items left in TODO.md
`### docshelf` group 6 (the lists per task below).

**Architecture:** No new modules. Each task owns a set of modules; tests
in `tests/test_docshelf.py`.

**Tech Stack:** Python 3 stdlib, `unittest`.

**Spec:** TODO.md items named in each task (their text is the
requirement) and the Decisions below (the user, 2026-11-17: "Start PR
4"). Each implementer reads the TODO text of its items first.

## Global Constraints

- Stdlib only. Version 0.7.2 (patch: fixes and tests) in `SKILL.md`
  `metadata.version` and `shelf_core.VERSION`, set in Task 4.
- Lookup output must not change except where an item says so.
- Tests hermetic (`clean_env()`, `run_cli()`, helpers), no network
  except a loopback `http.server` on 127.0.0.1 (6.2.2).
- Test output pristine (6.8.1: no warnings leaking to the test run's
  stderr; use `assertLogs`/captured stderr).
- Full suite from the repo root: `python3 -m unittest discover -s tests`
  (564 pass before this work).
- Public repo: no names, hostnames or absolute home paths.

## Decisions

- Scope: PR 4 leaves 6.13.25, 6.13.12, 6.9.2, 6.13.18 and 6.13.21 for a
  later PR (they need design decisions). Everything else in group 6 is
  here.
- A test-only item whose test fails exposes a bug: fix the bug in the
  same task if it's a few lines; otherwise stop and report it.
- 6.4.1: stamps use `st_mtime_ns` (or `st_mtime` without truncation),
  not whole seconds. Caches rebuild once after upgrade (note in the PR).
- 6.12.7: `name=` on `<details>` does not create an anchor (it's a group
  name, not a target).
- 6.13.3: a failure line in `install`/`update` always starts with
  "<name>: " (added in `_each` when the message doesn't already start
  with it).
- 6.13.4: `sources` dedupes slugs on the full list first (keep the first
  row overall), then filters.
- 6.13.10: an exit-2 error that will repeat for every name (e.g. an
  unwritable cache) stops the loop after the first one.
- 6.13.11: replacing an unheaded General keeps one blank line after the
  title.
- 6.13.13: tool argument descriptions use wording without flag syntax
  that reads right in both CLI help and MCP (e.g. "needs a text" /
  "the section's text"), not "--text" / "--set".
- 6.13.22 / 6.13.23: one "skipped N malformed entries" note per command;
  the Zeal-catalog note names the list(s) that actually fell back.
- 6.13.24: `install` of an up-to-date docvol whose `meta.json` lacks
  `entry_count` adds it (no download).
- 6.12.2: document the 3-pass limit of `unquote_all` in its docstring and
  test it.
- 6.12.5: `_has_parser_file` reuses `_scan_dir`'s filter; CMake parsing
  ignores `#` inside double quotes and `#[[ ... ]]` / `#[=[ ... ]=]`
  bracket comments.
